# NBU

University coursework organized by semester and subject.

## Structure

Each semester contains a `programming` directory with:

- `homework/` for assignments
- `projects/` for larger projects
- `notes/` for study notes
- `exams/` for exam preparation and materials

The semester directories currently cover semesters 01 through 08.
